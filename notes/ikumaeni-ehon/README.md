# 園館向け「いくまえに」絵本シリーズ 検討メモ

## 1. 発端と目的

- 発端：幼稚園・保育園の団体が、動物園で「みんなで大きな声で呼んでみよう」をやってしまう。引率する先生の認識が古いまま。
  - 参考：https://x.com/kurikararyuou/status/2109556792699322640
- 提案：園館が足並みをそろえて、遠足前に読む幼児向けの絵本を作る。
- 本当の狙い：**表向きの読者は子ども、変えたいのは引率の大人。** 読み聞かせを通じて先生の認識も新しくする。
- 広げる先：動物園・水族館だけでなく、博物館・美術館・図書館・植物園にも。

## 2. 基本の考え方

**見方や決まりを教えるだけでは足りない。子どもが自分ごととして受け入れられることが必要。**

幼児にとっての自分ごとの入り口は4つ。

1. **自分の体で感じたこと**（読み聞かせの途中で実際にやってみる）
2. **知っている誰か**（名前と顔のあるキャラクター）
3. **自分の役割**（客、探検隊など。決まりが役割から自然に出てくる）
4. **自分たちで決めたこと**（最後のページで約束を書きこむ）

本1冊で完結させず、**読む（園）→ 当日たしかめる（園館）→ 話す（帰ってから）** の流れで定着させる。

## 3. 決まりの理由の整理

決まりは「誰を・何を守るか」で理由が変わる。

| 守るもの | 決まり | 性質 |
|---|---|---|
| **もの**（博物館・美術館） | さわらない、フラッシュをたかない、飲食しない、ケースの近くで大声を出さない（つばが飛んで汚れる） | 基本は絶対 |
| **鑑賞**（博物館・美術館・図書館） | 静かに鑑賞したい人の妨げにならない声の大きさにする | 場合による。**大声そのものが悪いのではない** |
| **いきもの**（動物園・植物園） | 大声で呼ばない、ガラスを叩かない／根を踏まない、とらない | 生きものの暮らし（ご自宅）にお邪魔しているから |
| **みんなのもの**（図書館） | ていねいに扱う、借りたら返す | **さわっていい・借りていい**。次の人へ渡す |

- 博物館では、**大声でなければおしゃべりしてよい**し、**妨げにならなければ大声を出してもよい**。話す鑑賞はむしろ歓迎。
- **NG：「ほかの人が困るから」「みんなの迷惑」「怒られるよ」。**
  - 決まりが相手の反応しだいになる
  - 子ども自身が迷惑な存在として扱われる
  - 我慢の理由が「怒られないため」になる
- 代わりの理屈：**楽しみ方は人それぞれで対等。同じ部屋を分け合うから調整する。**
- 未就学児向けの手がかり：「こえのものさし」（0 しーん / 1 ないしょ / 2 となりに とどく / 3 クラス / 4 おそと）

## 4. 博物館版（未就学児）の設定

### 世界観：付喪神（つくもがみ）

- 長い年月を大切にされた道具には心が宿る。
- この理屈は博物館の決まりの本当の理由（長い時間を生きのびた、受け継がれてきた、一つしかない）と重なる。小学生向けの事実にも、そのままつながる。
- 『美女と野獣』のポット夫人型（物が仕える側）ではなく、**物が家の主・長老で、あなたが招かれた客**という関係にする。
- 怒って化けて出る妖怪ではなく、**大事にされて嬉しかった長老**として描く。

### 導入の流れ

> 自分の宝物 →「ずっと だいじに されると、ものには こころが やどる」→ はくぶつかんは だいじに されてきた ものたちの おうち → 土器の おじいさんから しょうたいじょう（あなたは まねかれた とくべつな おきゃくさま）

※「王子様・王女様」ではなく「とくべつな おきゃくさま」にして、性別で選ばせない。

### 物語の型：やらかす → 叱られる → 許される

- 未就学児には受け入れられやすい王道の型。呪いや罰とは区別する。
- **やらかすのは主人公**（読者ではない）。読者は「あーあ」と安全な距離から見られる。
- **怒る理由に本当の理由を入れる**（「てのあせで わしの からだが いたむ」）。
- やらかしは**未遂か小さな害**にとどめる（壊れたものが魔法で直る話はNG）。
- 長老は**ちょっと面白く怒る**（ふたや縁がカタカタ鳴る、など）。
- **繰り返しの構造**：部屋ごとに、やらかす → その付喪神が叱る → 理由 → ごめんなさい → 許して、ひみつを一つ教えてくれる。
- **最後に役割が入れ替わる**：後から来た誰かを主人公が止める →「りっぱな おきゃくさまじゃ、また おいで」。

### 場面の例

| 場面 | 理由 | 描き方 |
|---|---|---|
| 走る | ぶつかると壊れる | よろいの付喪神に叱られる |
| さわる | 手の脂や汗で傷む、さびる | 土器の長老に叱られる |
| フラッシュ | 色があせる | えのぐの付喪神に叱られる |
| ケースに顔を近づけて大声 | つばでガラスが汚れる | 「ぺっぺっ、つばが とんできたぞい！ わしの すがたが みえなくなる」（笑える叱られ場面） |
| 静かに見ている人のそばでおしゃべり | 鑑賞の妨げ | **叱らない。** 長老「あのひとは いま、あの えと こえを ださない おはなし を しておるんじゃ」→ 主人公が自分で声を小さくする |

最後の場面では、声で話す鑑賞（主人公）と心で話す鑑賞（おばあさん）を対等に描く。

### 先生にも届ける仕掛け（任意）

- 一緒に来た大人キャラが「おーい、みんなで よんでみよう！」とやらかし、長老に叱られる。
- 先生そのものに見せず、おじいちゃんやぬいぐるみなど、とぼけた大人にする。

## 5. 動物園版（未就学児）の設定

- 「動物の**ご自宅**にお邪魔する」が軸。
- 自分が動物になって友達のおうちへ遊びに行く、遠足の一日、などの設定が作れる。
- 名前のある同い年の動物（「ガオくん、4さい。きみと おなじ」）。
- 読み聞かせで体験：みんなで寝たふり →（先生が）「おーい！」→「びっくりした？」
- 役割は「どうぶつの ひみつを みつける たんけんたい」。
- ご褒美は**動物が近くに来ること**ではなく、**自分が見つけたこと**にする（来なかったときに「静かにしても無駄」と学習させない）。

## 6. 年齢別の設定

| | 未就学〜1年生 | 2〜4年生 / 5〜6年生 | 中学生以上 |
|---|---|---|---|
| 受け止め方 | ごっこ・物語に入りこむ | 作り話は子どもっぽい。本物・事実・公平さ・任されることに惹かれる | 決まりは知っている。課題は無関心やグループでのふざけ |
| 博物館 | 付喪神・招かれた客 | 調査員・学芸員見習いのミッション型。実験で理由を示す（10円玉を握ると変色する、など）。「きみが今日見られたのは、昔の人がさわらなかったから」 | 専門家の目を借りる（修復家、考古学者…）。正解のない問いを立てる |
| 動物園 | 動物のご自宅・友達のおうち | 飼育員の目で観察 | 展示や保全をめぐる問い |
| 自分ごとの入り口 | 体で感じる・誰かになる | 本物の役割・事実 | 見方を選ぶ自由 |

- 大きく変わる境目は入学時より**9〜10歳ごろ**ではないか（1年生はまだ物語設定を楽しめる）。
- 小学生以上の共通の問い：**「この決まりは、もの・鑑賞・いきもの・みんなのもの、何を守っている？」** 初めての場所でも、自分で決まりを導き出せるようにする。
- 中学生以上は「見方を教える」が鑑賞の授業にならないよう、**大人として扱い、決まりは理由を一度短く示して任せる**。

## 7. 引率の先生向けページ（巻末）

- 絵本と別に配ると読まれないので、**同じ本の中に入れる**。
- 決まりの理由（上の3の整理）。
- **団体は一人ずつの声が小さくても、合計で大きくなる。** 広がりすぎない、混んでいる部屋に長居しない、など場所の取り方で調整する。
- 「静かにしなさい」の言いすぎは、話す鑑賞を消してしまう。
- 言いかえの例：
  - ×「しずかにしなさい、迷惑でしょ」「怒られるよ」
  - ○「ケースの近くは、ないしょ声ね（つばがとぶから）」
  - ○「あの人は今、絵とお話ししてるみたい。小さい声にしよう」

- 届ける経路：**団体予約の確認や下見のとき**に渡す。PDFでも配る。図書館に置いてもらう。

- 業界全体の合意を待たず、1館か1地域で作り、使い回せる形で公開して広げる。

## 9. シリーズ構成

### 方針

- **まず未就学〜小学校低学年（4〜7歳くらい）向けを作り、シリーズ化する。** 元の問題（団体での引率）がいちばん起きる年齢で、読み聞かせという大人に届く経路があり、物語の設定が効く最後の年齢でもある。
- 施設の名前ではなく、**その場所で何を守るか**で巻の芯を決める。
- 作りやすいのは動物園版。作らないといけないのは博物館版。

### ラインナップ

| 巻 | 守るもの | 中心になる決まり | 優先度 |
|---|---|---|---|
| 動物園・水族館 | いきもの（ご自宅） | 呼ばない、たたかない、えさをやらない | 1期 |
| 博物館 | もの | さわらない、フラッシュをたかない、ケースの近くは小声 | 1期 |
| 図書館 | みんなのもの | **さわっていい・借りていい**。ていねいに扱って返す | 2期 |
| 美術館 | もの＋鑑賞 | 博物館とほぼ同じ。「見ること」そのものが主題 | 3期以降（反応を見て独立） |
| 植物園 | いきもの（動けない） | ふまない、とらない、もちかえらない | 3期以降 |

- 水族館は動物園と1冊にまとめ、水族館特有のこと（ガラス、暗さ、フラッシュ）は差しこみページで。
- **図書館版は他の巻と決まりの方向が逆**（博物館は「さわらない」、図書館は「さわって、借りて、返す」）。並べて読むと「決まりは場所によって違って、理由で決まる」ことが伝わる。シリーズにする一番の意味がここにある。未就学児がいちばん日常的に行く施設で、シリーズ全体の配布経路にもなる。
- 美術館は1冊目では博物館として作り、反応を見て独立させる。現代アートには触れていい作品もあり、決まりが一律ではない点に注意。
- 追加候補：**科学館**（さわっていいものと、だめなものが同じ館にある。区別する力そのものが主題になる）。寺社や史跡は宗教上の作法も絡むので後回し。

### 全巻共通の骨組み

1. 招待状が届く（あなたは招かれた客）
2. やらかす → 叱られる → 理由 → 許される（繰り返し）
3. 叱られない場面（自分で気づく）
4. 役割の入れ替わり（今度は自分が止める側）
5. 最後のページで約束を書く
6. 巻末に引率の大人向けページ

**「もの」「いきもの」「みんなのもの」「かんしょう」の4つのマーク**を全巻で共通にし、決まりの横に何を守っているかを示す。小学生向けの「この決まりは何を守ってる？」にそのまま育つ。

## 10. 各巻の長老

### 選ぶ基準

1. その場所で守るものの理由を体現している
2. どの館にもいる・ある（全国どこで読んでも、当日会いに行ける）
3. 本当に長く生きている・古い（長老であることが事実と結びつく）
4. 叱り方に体の特徴でユーモアが出る

**いきものの巻は本物の生きものが長老、ものの巻は付喪神が長老。** この区別自体が4つのマークの違いを表す。

### 決定

| 巻 | 長老 | 種類 |
|---|---|---|
| 動物園・水族館 | ゾウガメ | 本物の生きもの |
| 博物館 | 土器のおじいさん（ゲスト：化石） | 付喪神 |
| 美術館 | 額縁 | 付喪神 |
| 図書館 | 図鑑 | 付喪神（シリーズのハブ） |
| 植物園 | メタセコイア | 本物の生きもの（一族の長老） |

### 動物園・水族館：ゾウガメ

- 100年以上生きる。動物園にも水族館（ウミガメ）にもいる。
- **自分の家を背負っている**ので「ご自宅」の比喩そのもの。
- 叱り方：首をにゅーっと伸ばして「こらこら」。大声にびっくりすると首を引っこめる。
- ゆっくり話すので「しずかに、ゆっくり」の手本になる。ガラスを叩く場面の当事者にもできる。
- 次点はゾウ。ただしゾウのいない動物園が増えているので、汎用性ではカメが上。

### 博物館：土器のおじいさん

- 郷土資料館を含め、ほぼどの館にもある。何千年も前のもの。
- 叱り方：ふたや縁がカタカタ鳴る。
- 土器は破片をつなぎ合わせた復元品が多い。「わしは いちど われて、ひとが なんねんも かけて つないでくれた。でも、つぎめは きえんのじゃ」。**直しても元には戻らない**ことを長老本人が怖くない形で語れる（主に低学年向け。未就学児には継ぎ目の絵だけで十分）。
- 自然史系の博物館向けには**化石（恐竜）をゲスト**に。化石は道具ではないので付喪神の筋に乗らず、長老にはしない。

### 美術館：額縁

- どの絵にもついている。何百年も**見る人の顔を見てきた**側。「あの人は絵とお話ししている」場面の語り手にぴったり。
- 叱り方：金ぱくがきしむ、かざりのくるくるが逆立つ。
- 弱点：現代美術には額縁のない作品も多い。必要なら**美術館のベンチ**（ゆっくり座って見ることを勧める役）を相棒にする。
- 仕掛けの詳細は次の11。

### 図書館：図鑑

- 子どもが図書館で一番手に取る本。よく読まれ、よく傷み、よく修理される。**たくさんの手に読まれて心が宿った**。博物館の長老（さわられないことで長生きした）と逆の理屈で、シリーズ内の一番の対比になる。
- 図書館では**直して使い続けるのが普通**なので、博物館と逆の価値観を自然に見せられる。
- **何でも知っている物知り**。図鑑の中には動物も植物も化石も美術も載っているので、ほかの巻の長老を紹介できる（「ゾウガメの じいさんなら しっておるぞ、ほれ この ページじゃ」）。**シリーズのハブ**。
- 叱る場面：落書き、やぶる、ぬらす。
- 「返さない」は「つぎの こが こまる」ではなく、長老が「**つぎの こに あいたいんじゃ**」と言う。
- 注意：図鑑は館内だけで読む参考図書になっていることがある。→ 逆に使う。「わしは としょかんで まっている ほん。こっちの わかいのは おでかけする ほん」と、**館内で読む本と借りる本の違い**を長老が教える。
- 図鑑は新しい版に入れ替わる。低学年向けには「わしの しっている ことも、あたらしく かわっていく」と、**知識は更新される**話に使える。未就学児向けには触れない。

### 植物園：メタセコイア

- **化石で先に見つかり、あとから生きている木が見つかった。** 日本の研究者（三木茂）が化石から名前をつけ、その後に中国で生きている木が見つかった。「みんな わしは もう いなくなったと おもっておった」と、長老自身の物語が作れる。
- 日本の植物園、公園、学校に多く植えられていて、当日会いに行ける。
- 恐竜の時代から続く種。
- **博物館の巻とつながる。** 博物館では化石のメタセコイアに、植物園では生きているメタセコイアに会える。
- 叱る場面：根を踏む（踏み固められて根が傷む）、枝を折る、花や実をとる。
- 叱り方：葉っぱがざわざわ揺れて、実がぽとんと落ちる。
- 注意：日本の木は戦後に植えられたもので、一本一本は若い（長くて70年ほど）。長老である理由は**種としての古さ**。「わしの なかまは きょうりゅうの じだいから いきておる」と**一族の長老**として描く。
- 落葉する木なので冬は葉がない。季節で姿が変わることに絵本の中で触れておく（秋の赤茶色の並木）。
- ご神木のようにしめ縄をつけた描き方は避ける（宗教色が出る）。

### 実在の長老を差しこむ

全国共通の長老は本の中の存在。加えて、**館ごとの差しこみページに「この館の本当の長老」**を載せる。

- 動物園：その園の最高齢の動物
- 博物館：その館で一番古い収蔵品
- 図書館：その館で一番たくさん読まれた本
- 植物園：その園で一番古い木

「きょう、ほんものの ちょうろうに あいに いこう」が遠足の目的になり、帰ってからの振り返りにもつながる。館の側も自館の看板を出せるので協力を得やすい。

## 11. 美術館版の額縁の仕掛け

### 「絵の中に入る」は鑑賞の方法そのもの

- 「この絵の中にいたら、何が聞こえる？ どんなにおい？」は対話型鑑賞でも使われる問いかけ。「自分の体で感じたことが自分ごとになる」原則に乗る。
- 静かに見ている人の場面が強くなる。

> 長老（額縁）「あのひとは いま、えの なかに はいっておるんじゃ」
> 主人公「おおきな こえを だしたら？」
> 長老「えの なかから よびもどされて しまうのう」

「ほかの人が困る」ではなく、**その人の旅をさえぎる**。鑑賞の妨げが何なのかが体の感覚でわかる。

### 「入る」と「さわらない」がぶつからないように

- **額縁は、こっちの世界とあっちの世界の境目。** 空想の入口であると同時に**境界の番人**。
- 長老「はいれるのは め と こころ だけじゃ。からだは この せんの こっちに おいていきなされ」
- 美術館の床の線（作品に近づきすぎないための線）とも結びつく。

### 本の作り

1. **表紙＝額縁**：額縁を印刷した表紙。開くことが、絵の中に入ることになる。表紙を額の形に型抜きして1ページ目の絵が額縁越しに見える作りにするなら、印刷費が上がるのでストレッチゴール向き。
2. **途中：絵の中に入る見開き**：額縁の外から見た絵 → めくると主人公が絵の中に →「なにが きこえる？」。帰りもまた額縁をくぐる。行きと帰りで「入ったつもり」を区切る。
3. **最後のページ：空っぽの額縁**：子どもが自分の絵、または**自分の宝物**を描く。冒頭の「あなたの いちばん だいじな ものは なに？」に戻って物語が一周する。約束を書くページとまとめてもよい。
4. **おまけ：鏡のページ**：額縁の中に鏡の紙を貼り、のぞいた子どもの顔が額に入る。長老「わしは ずっと みるひとの かおを みてきた。きょうの かおは あなたじゃな」。見る側と見られる側が入れ替わる。印刷費と耐久性の点でストレッチゴール向き。

「表紙が入口になる」はほかの巻にも応用できるが、全巻でやると型どおりに見えるので、**美術館の巻だけの特別な仕掛け**にしておく。

## 12. クラウドファンディング案

### 強み

- **「近所の園に寄贈する」リターン**が作れる。支援者が地元の幼稚園・保育園・図書館に本を贈る形にすれば、資金と配布が同時に進む。元の目的（幼保に届ける）に一番まっすぐな形。
- 元ツイートに1,500以上のいいねがついていて、需要の兆しは見えている。

### 気をつける点

- **約束しすぎない。** 1〜2冊を約束し、残りはストレッチゴールに。
- **1期は動物園・水族館＋博物館の2冊同時。** 集めやすい動物園と、必要性の高い博物館の両方を取る。
- **監修者を立ち上げ前に確保する**（学芸員・飼育員・司書）。決まりの理由が正確でないと園館に置いてもらえない。「園館が足並みをそろえて」という元の提案に近づける意味もある。
- **印刷版はリターン、PDFは園館向けに無償ライセンス。** 目的は広まること。
- **類書の確認**を立ち上げ前に行う。
